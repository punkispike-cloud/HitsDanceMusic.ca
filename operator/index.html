Onboarder une nouvelle radio

5 étapes · ~quelques heures
  1. Créer la config + assets du client node scripts/new-client.mjs <slug> "Nom de la radio" Remplir brand/<slug>.json (couleurs, flux, domaines) et déposer le logo.
  2. Bâtir son site (sur sa branche) BRAND=<slug> node scripts/build-all.mjs Optionnel : préparer un seed de départ (api/src/db/seed-<slug>.ts + seeds.ts) pour booter sa grille.
  3. Déployer l'instance Railway Nouveau projet : Postgres + api + web + admin. Variables : JWT_SECRET unique, ALLOWED_ORIGINS, SEED_BRAND=<slug>. (Voir ONBOARDING-CLIENT.md.)
  4. Vérifier le déploiement node scripts/verify-deploy.mjs https://<api-du-client> Doit afficher 4 ✅ (API/DB, grille, animateurs, push).
  5. Enregistrer le client Ajouter l'entrée dans brand/clients.json (status, domaines, palier, ⚖️ attestation licences) → il apparaît ici.
Modèle « une instance par client » · Le portail multi-tenant viendra vers ~5 clients.
